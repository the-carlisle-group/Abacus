# AlertBox New Method

Creates a new AlertBox.

~~~
    R←{D} New X
~~~

`D` is an optional Document.
`X` is a namespace, or a shortcut list, of properties: see the AlertBox properties.
`R` is the new AlertBox.

Display it with the [Show]() method. For the simple case use the HTMLDocument [Alert]()
method, which combines `New` and `Show`.
